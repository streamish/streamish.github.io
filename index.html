Streamish Music

Free and private self-hosted music server for multiple users with browser interface and compatible with multiple Android and iOS apps.

  1. Docker image
  2. API documentation
  3. View on GitHub

Get started with Docker Compose

services:
  streamish:
    image: streamish/music
    ports:
      - "8000:8000"
    volumes:
      - /my/music:/music:ro
      - /my/data:/data:rw
    environment:
      DEFAULT_ADMIN_USERNAME: admin
      DEFAULT_ADMIN_PASSWORD: admin
      # SYNOLOGY_AUDIOSTATION_ENABLED: true
      # QNAP_MUSIC_STATION_ENABLED: true
      # SUBSONIC_ENABLED: true
